## API routes (`/v1/...`)

Global **Bearer JWT** on all routes except **`/docs*`** (OpenAPI, when enabled; no JWT for UI and JSON spec), `GET /health` (liveness: uptime + time), `GET /health/ready` (readiness: **503** if DB down), `GET /health/summary` (liveness + DB + version + `uptimeSec` in one JSON, **503** if DB down — for a single monitor probe), **`GET /metrics`** (Prometheus text exposition, A6 — no JWT; restrict at the edge), `POST /auth/login` and `POST /auth/register` (register only if `AUTH_ALLOW_REGISTER=true` in env), **`POST /payments/stripe/webhook`** (verified with `STRIPE_WEBHOOK_SECRET` + **raw** body), and the unauthenticated read-only **public** routes below (each requires **`companyId`** in the query; server checks that stations/classes belong to that company; **`@Public()`** + per-controller throttle **50** requests / **60s** / IP for `GET` under **`/v1/public/`**).

### Public (no JWT)

| Route | Query | Purpose |
|-------|--------|--------|
| `GET /public/catalog` | `companyId` (UUID) | Company name, stations, vehicle classes, **B4** `privacyNotices` (version / optional policy URL / effective date) for **`/quote`** |
| `GET /public/quote` | `companyId`, `vehicleClassId`, `pickupAt`, `returnAt`, optional one-way `pickupStationId` + `returnStationId` | Same rent math as **`GET /rates/quote`**, `RateService.quotePublic` |

| `POST /public/quote-reservations` | JSON body `publicCreateQuoteBodySchema` (company, class, `stationId` = home for availability, pickup/return stations + times, **customer** name/email/phone, optional `notes`, **B4** optional **`privacyNoticeVersion`** + **`marketingEmailOptIn`** — required server-side when the company privacy register is non-empty; **C1** optional **`extraLines`** (max **12**), same shape as desk) | **201** — **`ReservationService.createPublicQuote`**: upserts **`Customer`** (unless email matches an **anonymized** profile), validates **`privacyNoticeVersion`** against **`CompanyPrivacyNotice`**, audit **`customer.b4_public_quote`** when consent fields change; auto **total** includes extras; **C3** **`publicViewToken`**; throttle **5 / 60s / IP**; optional SMTP ack |
| `GET /public/reservations/by-view-token` | `token` = hex (32–64 chars, from quote save) | **C3** — read-only summary for **`PUBLIC_WEB`** (company name, class, stations, times, **status**, **totalCents**, **`extraLines`**, **paidAt** / **deposit** state); no notes/Stripe ids; **throttle: 30 / 60s / IP**; wrong/missing → **400** (bad format) or **404** |

CORS: allow your web origin in **`CORS_ORIGINS`** (e.g. `http://localhost:3001`).

- **`ADMIN`**: can list all companies; optional `companyId` filters. Other roles: data is **limited to their `companyId`**; mismatched `companyId` in query → **403**; wrong `GET …/:id` in another company → **404** (on purpose).
- **`AGENT`** with a set `User.stationId` (“home” branch): reservations (list / get / mutate), vehicles, calendar blocks, stations list, availability, rate quote (with `pickupStationId`), CaRGOS, agreements, and Stripe checkout are **scoped to that station** (read: reservation **touches** pickup or return; mutates: **pickup** must be at that station). Agents with no `stationId` behave as before (company-wide).
- **Mutations** (POST / PATCH / DELETE on org/fleet/reservations, except as noted): **`@Roles(ADMIN, BRANCH_MANAGER, AGENT)`** — **`READONLY_ACCOUNTING`** is read-only (GET+availability). Companies: `POST/DELETE` **`ADMIN` only**; `PATCH` **`ADMIN` or `BRANCH_MANAGER`** (own company only for branch manager).

## Business rules (half-open time)

- Intervals are **[pickup, return)** (and blocks **[starts, ends)**). Overlap: `aStart < bEnd && bStart < aEnd` — see [`apps/api/src/fleet/intervals.ts`](../apps/api/src/fleet/intervals.ts).
- A reservation **counts** against the vehicle for availability unless `status` is one of: **`CANCELLED`**, **`COMPLETED`**, **`NO_SHOW`** (`@car-rental/shared`: `reservationNonBlockingStatusValues`). That includes **`QUOTE`**: draft quotes still hold the slot in this v1.
- **Source:** `Reservation.source` is **`STAFF`** (desk created), **`PUBLIC_WEB`** (POST `/v1/public/quote-reservations`), or **`PARTNER`** (**`POST /v1/partner/reservations`**); shown on the desk list and edit form; only staff flows set **`STAFF`** — not client-writable on public/partner routes beyond API-defined create.
- **Odometer:** optional **`odometerOutKm` / `odometerInKm`** on the reservation; desk **PATCH**; when status is **`COMPLETED`** and **in** km is set, **`Vehicle.odometerKm`** is updated to match return odometer.
- **Pricing:** optional `totalCents` (minor units) + `currency` (default `EUR`); **v1** model **`PER_CLASS_DAY_24H`**: rent = **sum of daily rates** over `countRentalDays24h` (each billing day: UTC date → optional **`VehicleClassSeasonalRate`** or `defaultDailyCents`) + company **one-way** + **`ReservationExtraLine`**; manual total vs auto total **not mixed** with extras; optional `defaultDepositCents` on class (used for **deposit hold** link). **Card payment (optional):** Stripe Checkout for **rent** (EUR) + webhook to **`paidAt`**; **deposit** = separate Checkout with manual capture, then capture/release via API. **VAT** display only in desk, not in API.
